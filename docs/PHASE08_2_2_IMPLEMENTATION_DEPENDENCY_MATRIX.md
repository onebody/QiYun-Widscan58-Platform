## 0. 硬性规则

1. 禁止多站点 UI 先于多站点后端。
2. 禁止前端 WS 订阅先于认证/授权/审计/限流。
3. 禁止设备命令先于完整授权链。
4. 禁止用前端隐藏按钮替代后端授权。
5. 禁止把网络隔离作为唯一安全措施。
6. 禁止本阶段修改冻结协议。
7. 任何任务实施前必须获得对应审批；**08.2.1 与 08.2.2 全部 ADR 当前为 PROPOSED**。

## 2. 关键任务说明

### SP-01 认证基础设施

- **DB**：新增 `users`、`sessions`；`users.permission_version`。
- **API**：`POST /api/v1/auth/login`、`POST /api/v1/auth/logout`、`GET /api/v1/auth/me`。
- **不兼容点**：首次部署需初始化管理员（离线 CLI 或环境变量一次性注入）。
- **回滚**：功能开关 `AUTH_ENABLED=false`（仅过渡期，且必须绑定回环）。

### SP-02 REST 认证中间件

- 所有 `/api/v1/*` 除 `/health`、`/auth/login` 外必须认证。
- `AuthContext` 注入；失败 401，无业务数据。
- 回滚：开关关闭（风险极高，仅限本地调试）。

### SP-03 Site Scope

- 移除 `sid = site_id or cfg.site.id` 的信任语义，改为 `AuthContext` 过滤。
- 设备/测量端点增加资源反查。
- 测试必须覆盖 AZ-08/09/10。

### SP-10 Agent 凭证

- 轮换端点、撤销即断、连接复核、读端点认证。
- **不得**引入 nonce 等协议变更（需单独批准）。
- Agent 兼容：旧 Agent 继续使用现有首消息认证。

### SP-11 设备归属校验

- 现网可能存在历史“先上报即认领”的设备。
- 上线前需数据盘点；首版可“告警不拒绝”，二版转拒绝。
- 回滚：降级为告警。

### SP-12 前端 WS

- 必须 SP-02/03/04/06/07/09 全部完成。
- 票据 30 s、单次、绑定 Scope。
- 未获批准前**不得实施**。

### SP-15 设备命令

- 需协议变更审批（远端 `command.request` 分发）。
- 必须完成双平面授权链。
- 高风险命令 step-up。

### SP-17 WP-02

- 与安全任务独立；但**是 08.3 的硬门禁**。
- 见 §4。

### 3.1 禁止的逆序

| 禁止 | 原因 |
