## 1. 测试原则

1. **真实硬件、真实接口、真实页面**；不得用 Mock、静态 HTML、历史截图或合成图替代。
2. 每个用例必须留存：命令/脚本、原始响应、截图、日志时间戳。
3. 区分四类结论：`代码检查通过`、`自动化测试通过`、`历史数据回放通过`、`真实硬件验证通过`；不得混用。
4. 未执行 = `NOT VERIFIED`；被前置阻塞 = `BLOCKED`；不得默认 PASS。
5. 删除/跳过/降低断言一律不允许。
