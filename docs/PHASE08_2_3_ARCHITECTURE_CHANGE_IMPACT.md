## 1. 总原则

1. 本阶段**不批准**任何既有 ADR，也不提升任何 ADR 状态。
2. 新需求对既有 ADR 的影响分为：`无影响` / `需补充说明` / `需修订` / `新增 ADR`。
3. 新需求产生的实施任务一律编号为 `SP-RF-*`，**不改写 SP-00–SP-17 的定义与状态**。
4. 任何“需固件变更”的项，均**不在本阶段授权范围**，必须单独立项。

## 9. 影响结论

1. RF 需求**不推翻**既有 ADR，但要求对多站点、事件流、权限、安全四组 ADR 追加条款。
2. RF 只读分析对 **SP-02/03/04** 有硬依赖；在这些安全基础落地前，实施会引入新的越权风险。
3. **固件是最大阻塞**：40+ 并发频点、SoftAP、节点服务端均需固件变更，且不得借此修改冻结协议。
4. WP-02 D01 必须先明确处理方式，否则 RF 在线/过期语义不可信。
5. 本阶段不启动 Phase 08.3，也不启动 SP-00–SP-17。
