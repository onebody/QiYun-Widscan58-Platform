## 3. 安全未批准时的禁止实施清单

若 A2（12 份安全 ADR）未获批准，以下功能**一律不得实施**：

| 类别 | 禁止项 | 原因 |
|---|---|---|
| 接口 | `/api/v1/rf/*` 全部读写接口 | 无认证/授权模型 |
| 接口 | 现有 REST 的写端点扩展 | 无 CSRF/Origin 策略 |
| 页面 | RF Workbench 四页面（涉及数据查询） | 依赖未授权接口 |
| 页面 | 节点连接/断开/配置按钮 | 无二次授权链 |
| 数据服务 | 节点接入登记、频道计划写入 | 无 Site Scope/Resource Scope |
| 实时通信 | `/ws/v1/site`、RF 推送 | 无 WS 票据与订阅授权 |
| 多站点 | Site 切换器、跨站查询 | 无 Site Scope |
| 机器平面 | 平台直接调用 Agent 命令 | 违反双平面隔离 |
| 凭证 | 节点凭证下发/轮换 UI | 无凭证生命周期 |

> 只读代码审计、文档设计、离线推导不受此限制。
