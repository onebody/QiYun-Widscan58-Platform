## 2. 审阅口径

每份 ADR 按 8 个方面判断：

1. 安全目标是否明确；
2. 威胁模型是否充分；
3. 信任边界是否明确；
4. 认证与授权是否分离；
5. 凭证是否有生命周期管理；
6. 失败时是否安全关闭（fail-closed）；
7. 是否有可测试的验收条件；
8. 是否存在尚未解决的安全漏洞或设计缺口。

判断结果用：`明确` / `基本充分` / `部分` / `缺失` / `不适用`。
**合理性 ≠ 已实现。** 所有“已设计”项在未实施前一律不能作为验收证据。
