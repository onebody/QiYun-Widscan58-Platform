## 2. 通用布局（1920×1080 主目标）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 顶栏：当前 Site · 刷新状态 · 数据时间范围 · 实时/暂停 · 异常徽标              │
├──────────────┬─────────────────────────────────────────────────────────────┤
│ 左侧导航      │ 页面标题 + 说明                                             │
│ (现有 7 项   │─────────────────────────────────────────────────────────────│
│  + RF 4 项)  │ 选择器区：节点 / 频点 / 时间 / 聚合                          │
│              │─────────────────────────────────────────────────────────────│
│              │ 主图表区（固定高度，独立滚动，不推动页面）                    │
│              │─────────────────────────────────────────────────────────────│
│              │ 图例 / 状态条 / 数据完整性与缺失统计                          │
└──────────────┴─────────────────────────────────────────────────────────────┘
```

布局约束：

- 主图表区高度固定（例如 560 px），超出内部滚动；页面不出现双层滚动条。
- 选择器区高度固定，超长节点列表用下拉 + 搜索，不在页面内展开成长列表。
- 1366×768 下允许图例折叠，但不得隐藏重要状态。

## 3. Node Management（`#/rf/nodes`）

### 3.1 布局

```
┌ 节点列表（表格，占 60%） ─────────────┬ 节点详情抽屉（40%） ────────────────┐
│ ID | 名称 | 接入方式 | 状态 | 最后心跳 │ 身份 / 能力 / 频道计划 / 接入配置   │
│    | 固件 | 频点上限 | 置信度          │ 连接操作（未实现则禁用并说明）      │
└───────────────────────────────────────┴────────────────────────────────────┘
```

### 3.2 表格字段

| 列 | 来源 | 缺失显示 |
|---|---|---|
| Node ID | `node_id` | `—` |
| 名称 | `devices.display_name` | `—` |
| 接入方式 | `node_capabilities.access_modes` | `未知` |
| 状态 | 设备状态 + 心跳 | `未知`（不得默认“在线”） |
| 最后心跳 | `last_seen_at` | `未提供` |
| 固件版本 | `firmware_version` | `未提供` |
| 频点上限 | `max_concurrent_channels` | `未提供` |
| 身份置信度 | `identity_confidence` | `—` |

### 3.3 操作

| 操作 | 现状 | UI 处理 |
|---|---|---|
| 查看详情 | 可读设备信息 | 可用（复用现有） |
| 连接 / 断开 | 平台无写接口 | **禁用 + 文案“后端未提供”** |
| 手动添加 IP | 无接口 | 禁用或引导至文档，不伪造成功 |
| 修改频道计划 | 无接口 | 禁用 |

### 3.4 筛选

- 接入方式：全部 / USB / Wi-Fi LAN / AP Direct。
- 状态：在线 / 离线 / 过期 / 待认领。
- 搜索：Node ID / 名称。
- 空结果必须显示“无匹配节点”，不显示骨架屏假数据。

## 4. RF Spectrum（`#/rf/spectrum`）

### 4.1 用途

X 轴频率、Y 轴 RSSI，多节点独立曲线；支持 40+ 频点（目录），但**当前节点只能同时观测 ≤8 频点**。

### 4.2 选择器区

| 控件 | 规则 |
|---|---|
| 数据模式 | `频道级` / `频谱箱`；默认 `频道级` |
| 节点选择 | 多选，≤ 8；显示在线/离线/过期徽标 |
| 频点选择 | 频道级模式多选，**≤ 8**；达到 8 个时其余置灰并提示“最多 8 个” |
| 时间 | `当前快照` / `最近 1 min` / `最近 5 min` |
| 显示 | 是否显示网格、是否显示过期节点、是否仅显示已校准 |

### 4.3 图表

- X 轴：频率（GHz，保留 3 位小数）；Y 轴：RSSI。未校准显示 `dBFS`，已校准显示 `dBm`。
- 每个节点一条曲线；颜色按节点分配（见 §7）。
- 频点级模式：标记点 + 阶梯/折线；频谱箱模式：连续曲线。
- 图例：可单击隐藏/显示单条曲线；隐藏状态在 URL 中保留（可选）。

### 4.4 状态

| 状态 | 展示 |
|---|---|
| 实时 | 顶栏“实时刷新 · 最近更新 HH:MM:SS” |
| 暂停 | “已暂停” + 恢复按钮 |
| 过期 | 曲线降透明度 + `stale` 标记，不移动为实时 |
| 无数据 | 空状态“所选节点在窗口内无数据” |
| 未校准 | Y 轴标签 `dBFS` + 徽标“未校准” |
| 计划未知 | 徽标“频率来源未知” |

## 5. Multi-Node Analysis（`#/rf/analysis`）

### 5.1 两种模式

| 模式 | 说明 | 系列 |
|---|---|---|
| 同频点多节点 | 固定频道，比较多个节点 | 节点 × 频道 |
| 单节点多频点 | 固定节点，比较多个频道 | 频道 |

### 5.2 选择器区

- 模式切换（分段控件）。
- 模式 A：节点多选 ≤8，频道多选 ≤8（通常 1 个）。
- 模式 B：节点单选 1 个，频道多选 ≤8。
- 时间范围：`15 min` / `1 h` / `6 h` / `24 h` 自定义。
- 聚合：`avg` / `min` / `max`；桶宽自适应（1/5/10/60/300 s）。

### 5.3 图表

- X 轴时间（本地时区显示，tooltip 显示 UTC）。
- Y 轴 RSSI（dBFS/dBm 同上）。
- 缺失区间：断线，不插值；tooltip 显示“无数据”。
- 节点重启：断点标记“重启”，可开关。
- 系列数上限 64（8×8），超过时提示缩小选择。

### 5.4 辅助信息

- 图例：系列名 + 当前值 + 最后更新时间。
- 统计条：样本数 / 期望数 / 缺口数 / 过期节点数。

## 6. RF Heatmap（`#/rf/heatmap`）

### 6.1 布局

```
X 轴：频点（≤8 或 40+ 目录，按选择）
Y 轴：节点（≤8）
单元格：RSSI 统计值 + 样本数
右侧：色标（min/max，单位 dBFS 或 dBm）
底部：时间窗口选择 + 桶宽
```

### 6.2 规则

- **绝不跨节点合并**；每行独立。
- 缺失单元格：空白/斜纹 + “无数据”，不填 0。
- 过期单元格：边框虚线 + tooltip“最后更新 …”。
- 未校准：色标标注 `dBFS`；`calibrated_only=true` 时未校准单元格为空。
- 时间窗口：`1 h` / `6 h` / `24 h` / `7 d`；桶宽 60/300/3600 s。
- 悬停显示：节点、频道、频率、值、样本数、期望数、质量。

### 6.3 40+ 频点的显示

- 目录可展示 40+ 列，但视野需要横向滚动；列宽固定，粘性 Y 轴。
- 若节点仅覆盖 8 频点，未覆盖列为 `plan_unknown` / `missing`，不显示猜测值。

## 7. 颜色、图例与系列命名

### 7.1 颜色分配

沿用 Phase 08.3 已有 `--s1..--s8` 系列色（与 Console/Workbench 对齐）。

| 模式 | 颜色编码维度 | 上限 |
|---|---|---|
| 频谱 · 多节点 | 节点 | 8 |
| 趋势 · 同频点多节点 | 节点 | 8（多频道时用线型区分） |
| 趋势 · 单节点多频点 | 频道 | 8 |
| 热力图 | 连续色标（非分类色） | — |

规则：

1. 同一图表内**颜色只编码一个维度**，另一维度用线型/标记区分。
2. 节点颜色在会话内稳定（按 node_id 排序分配），刷新不跳色。
3. 超过 8 个节点：阻止添加，不循环复用颜色。

### 7.2 系列命名

- 默认：`<节点短名> · <频道>`，例如 `Node-01 · R1`。
- 节点短名优先 `display_name`，否则 `node_id` 后 6 位。
- 图例最多 2 行文本，超出省略并保留 tooltip 全名。
- 导出/分享时系列名保持稳定，不使用序号 `Series 1`。

### 7.3 无障碍

- 状态不只靠颜色：`online/stale/missing/uncalibrated` 均有文字 + 图标/线型。
- 色觉友好：避免仅红/绿区分；使用形状差异。

## 8. 刷新、错误与空状态

| 场景 | 要求 |
|---|---|
| 实时刷新 | 1–2 s 轮询（首版）；页面隐藏时暂停；恢复时补拉窗口 |
| 刷新状态 | `刷新中` / `已暂停` / `刷新失败（重试中）` / `最近更新 HH:MM:SS` |
| 服务不可达 | 顶部横幅“Site Server 不可达”，保留最后数据并标 `stale` |
| 401/403 | 明确“无权限”，不显示空白图表当作无数据 |
| 窗口过大 | 提示缩小时间范围（对应 `RF_WINDOW_TOO_LARGE`） |
| 超过 8 频点 | 明确提示“最多 8 个”，不静默截断 |
| 无节点 | 空状态引导至 Node Management |
| 未实现能力 | 按钮禁用 + “后端未提供”，不弹“成功” |
