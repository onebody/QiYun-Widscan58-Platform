# Phase 08.3 — 统一 UI 设计规范

> 阶段：Phase 08 Platform UI Integration / 子阶段 08.3
> 性质：**设计规范文档，不修改代码**
> 日期：2026-11-05
> 适用范围：site-server 同源托管的 Platform Shell（Overview / Sites / Gateways / Devices / Measurements / System）
> 不适用范围：原始 widscan58 Web Console（`repo/web`）、Electron 壳、Android App、rftrack Workbench —— 它们保持现有视觉与操作方式。

---

## 1. 设计原则

1. **专业 RF 监测台，不做营销页**：深色中性底、低饱和面、单一强调色；颜色只用于状态与数据，不用于装饰。
2. **桌面信息密度优先**：13 px 基准字号、36 px 表格行高；1920×1080 是主目标，1366×768 必须可用。
3. **状态一眼可见**：在线/离线/待认领/错误/未实现必须有文字 + 颜色 + 形状三重编码，不依赖单一颜色。
4. **数据真实性优先于视觉统一**：接口没有的字段显示“未提供/未实现”，不得用占位数据、假图表、假总数。
5. **不改 Console 的操作效率**：平台不内嵌、不压缩频谱/Waterfall；Console 保持全屏面积与原有交互。
6. **克制动效**：只允许 120–160 ms 的透明度/颜色过渡；禁止大面积位移、旋转、循环动画、装饰性渐变。
7. **同源同语义**：颜色变量名与 rftrack Workbench / Console 既有 `--s1..--s8/--good/--warning/--critical` 对齐，避免同一状态两种颜色。

### 2.4 间距与圆角

- 间距基数 4 px：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 卡片内边距 16；卡片间距 16；页面内容左右内边距 24。
- 圆角：卡片 6 px、控件 4 px、徽标 3 px；不使用大圆角（>8 px）。
- 表格行高 36 px（宽松 40），表头 40 px。

### 2.5 布局尺寸

| 区域 | 尺寸 |
| --- | --- |
| 顶部栏 | 高 48 px |
| 主导航 | 宽 220 px；<1280 px 折叠为 56 px 图标栏 |
| 内容区 | 左右 24 px；顶部 20 px；底部 24 px |
| 底部状态条 | 高 28 px |
| 页面最大宽度 | 不限制；内容按 12 列栅格自适应 |
| 表格最小宽度 | 按列内容；容器横向滚动，首列 sticky |

12 列栅格：列间距 16 px；Overview 卡片按 3/3/3/3 或 4/4/4 排列；1366 宽下自动降为 6/6。

## 3. 全局布局

### 3.1 顶部栏（48 px）

```
[产品标识 16px 粗体] [Site 名称 / site_id] ·  [服务状态灯 + 文本] · [最近刷新 hh:mm:ss]   [RF Console ↗]
```

- 左侧固定；右侧 `RF Console` 为文本链接 + 外链图标，不做大按钮。
- 服务状态灯规则见 §2.2；不可用状态显示灰色，不显示假绿灯。
- 顶部栏不放置搜索框（本阶段无跨实体搜索接口）。

### 3.2 主导航（220 px）

- 文本 + 16 px 线性图标；选中项用 `--accent` 左侧 2 px 竖条 + `--surface-2` 背景，不使用整块高亮按钮。
- 导航项顺序固定：Overview、Sites、Gateways、Devices、Measurements、RF Console（分组线以上）；System 置于底部（分组线以下）。
- 未保存状态不做“红点”提示（无写操作）。

### 3.3 内容区

- 页面头部：标题（20 px）+ 一句话说明（11 px muted）+ 右侧仅“刷新”文本按钮。
- 分区标题与内容间距 12 px。
- 不使用全页大卡片包裹；每个分区独立卡片。

### 3.4 底部状态条（28 px）

```
Site Server: 已连接/不可达 · 数据来源: 真实 API · 最近刷新 12:00:03 · WebSocket: 未实现（轮询） · 版本: 未提供
```

- 字号 11 px；`不可达` 用 `--critical`，`未实现` 用 `--disabled`。
- 状态条始终可见（`position: sticky; bottom: 0`）。

## 4. 组件规范

### 4.1 统计卡片（Stat Tile）

```
┌─────────────────────────────┐
│ 标签 11px muted             │
│ 数值 28px mono              │
│ 辅助：在线 8 / 共 10  · 11px │
└─────────────────────────────┘
```

- 保持等高（88 px）；数值不做动画计数。
- 点击进入对应列表（整卡可点，键盘可达）。
- 数据缺失：数值显示 `—`，辅助文本“接口未提供”。

### 4.2 卡片（Card）

- 背景 `--surface`；边框 1 px `--border`；圆角 6 px；内边距 16 px。
- 标题 14 px 600；右上角可放状态徽标或“查看全部”文本链接。
- 禁止阴影堆叠；仅允许 1 px 边框与背景层级区分。

### 4.3 表格（Table）

- 表头 40 px，`--surface` 背景，11 px 大写字距 0.04em，`--muted`。
- 行高 36 px；分隔线 1 px `--grid`；**不使用斑马纹**。
- 悬停行背景 `--surface-2`；当前选中行左侧 2 px `--accent` 竖条。
- 数值右对齐、时间戳等宽数字右对齐、文本左对齐、状态列居中。
- 长 ID/event_id：等宽字体，允许 `word-break: break-all`，不省略到不可辨认（必要时两行）。
- 首列（名称/ID）`position: sticky; left: 0`，背景不透明。
- 空值统一显示 `—`（em dash），不显示 `null/None`。
- 表格容器最大高度按视口，表头 sticky。

### 4.4 过滤与分页

- 过滤器放在表格上方一行：标签 + 原生 `select`（沿用浏览器控件，统一 32 px 高）。
- 仅提供后端真实支持的过滤：`status`、`only_adopted`、`site_id`（Agent 列表支持）。
- 不提供假过滤（如 `transport_type`、时间范围）。
- 分页：`上一页 / 下一页` + “已加载 N 条”；无 total 时不显示总页数。
- 过滤变化立即重新拉取，不做“应用”按钮。

### 4.5 状态徽标（Badge）

- 高 20 px，内边距 6 px，字号 11 px，圆角 3 px。
- 背景为对应色的 12% 透明度，文字为状态色本身（深色主题下保证对比度）。
- 徽标内可带 6 px 圆点/三角；不只用颜色区分。
- 示例：`● 在线`、`◇ 离线`、`▲ 心跳超时`、`● 错误`、`· 未实现`。

### 4.6 按钮与链接

- 本阶段只有“刷新”和导航/外链：
  - 刷新：32 px 高，透明背景，1 px 边框，文本 + 旋转图标（加载时 1 s 旋转，结束后停止）。
  - 外链：文本链接 + `↗`。
- 不出现主操作按钮（新建/编辑/删除/认领/迁移）——与只读边界一致。
- 禁用按钮必须显示原因 title，不显示无解释的灰按钮。

### 4.7 图表规范

平台管理页**只允许展示有真实来源的图表**：

| 图表 | 数据来源 | 形式 |
| --- | --- | --- |
| Ingestion 计数器 | `/api/v1/diagnostics.ingestion` | 水平条形（单色 `--accent`，值为 0 时显示空条 + 0） |
| Agent/Device 在线占比 | 列表计数 | 细环形或水平堆叠条，必须标数值 |
| 无时间序列数据 | — | **不画趋势线**；显示“后端未提供时间序列” |

**明确禁止**：

- 用 Measurement 的 payload 猜造频谱曲线；
- 用随机/平滑数据填充趋势图；
- 在平台页绘制频谱或 Waterfall（它们属于 Console，保持原位与面积）；
- 自动轮播、动画重绘。

图表颜色语义：

- 网格 `--grid`、坐标轴 `--axis`、文本 `--muted`；
- 主序列 `--accent`；总量/参考线 `--ink-2`（虚线）；
- 状态相关图（如重复事件）用对应状态色，不用强调色替代。

### 4.8 弹窗（Dialog）

- 本阶段无写操作，**不设计业务弹窗**。
- 唯一允许的浮层：JSON payload 查看器（也可用行内展开，优先行内）。
- 若必须弹窗：最大宽 720 px，背景 `--surface`，遮罩 `rgba(0,0,0,.6)`，标题 16 px，关闭按钮键盘可达，Esc 关闭。

### 4.9 消息提示（Toast）

- 仅用于“刷新失败/已恢复”等瞬时反馈；右下角，宽 ≤360 px，自动消失 5 s。
- 同一错误合并为一条（带次数），不堆叠超过 2 条。
- 不用于成功写操作（没有写操作）。

### 4.10 空状态

```
[16px 线性图标]
尚未配对 Gateway Agent
说明一句话（11px muted）
[可选：指向 System 或文档的文本链接]
```

- 空状态区域高度 ≥160 px；不使用插画大图。
- 空状态必须区分：`无数据（接口成功返回空）` vs `未实现（接口不存在）`。

### 4.11 加载状态

- 列表：骨架行（3–5 行，高 36 px），不覆盖整页 spinner。
- 详情：骨架块；保留页面框架与导航。
- 刷新中：顶部“刷新”图标旋转；已有数据不清空。
- 首屏加载 >1 s 才显示骨架（避免闪烁）。

### 4.12 错误状态

- 行内错误条：`--surface-2` 背景 + 2 px 左边框 `--critical`；显示 HTTP 状态、端点路径、重试按钮。
- 若已有上一次成功数据：保留数据 + “数据陈旧（hh:mm:ss）”角标，不整页清空。
- 401/403：显示“未授权（401/403）”，不自动重试。
- 5xx：指数退避重试并显示“服务端错误（5xx）”。
- 不显示堆栈、不显示内部异常原文。

### 4.13 未实现状态

- 使用中性灰文本 + 虚线下划线，例如“未实现（后端未提供时间范围过滤）”。
- 与空状态视觉明显不同：空状态有图标与主文案；未实现是行内注记。
- **禁止**把未实现按钮做成可点击后无反应。

## 5. 页面级视觉规则

### 5.1 Overview

- 4 个统计卡片一行（1920）→ 2×2（<1440）。
- 下方左右两栏：系统状态（宽 7 列）+ 最近数据/告警（宽 5 列）。
- 最近告警不存在时，整卡显示“未实现（无告警数据源）”，不隐藏卡片。

### 5.2 Sites

- 单站点时仍显示列表，只有一行；表头完整，避免“特殊页”分支。
- 详情页上方 4 个统计 + 下方 Agent 表。

### 5.3 Gateways / Devices

- 表格为主，不卡片化。
- 状态列固定宽 96 px；最后心跳列固定宽 160 px。
- 详情页左侧身份卡（宽 380 px）+ 右侧分区；<1366 时上下堆叠。

### 5.4 Measurements

- 顶部必须有 Device 选择器（唯一必需过滤）。
- 三时间戳列并排，宽度一致；`agent_received_at` 列在接口未返回时整列显示 `—` 并在表头加“未提供”角注。
- `payload` 行内展开：等宽字体、最大高 320 px、可滚动、保留原始 JSON 缩进；不做语法高亮依赖。

### 5.5 System

- 两组：运行状态（health/diagnostics）+ Ingestion 计数条。
- 版本/日志/配置缺失项各占一行，明确“未实现”。

### 5.6 RF Console

- 平台导航仅提供外链；不设计任何内嵌布局。
- 平台不得修改 Console 的样式、画布尺寸、交互；不做“统一换肤”。

## 6. 响应式与密度

| 宽度 | 行为 |
| --- | --- |
| ≥1920 | 内容全宽，卡片 4 列，表格无横向滚动 |
| 1440–1919 | 卡片 4→3 列；表格按需横向滚动 |
| 1280–1439 | 导航 220 px 保持；卡片 2 列；统计字号不变 |
| 1024–1279 | 导航折叠为 56 px 图标栏（hover 显示文字）；详情卡上下堆叠 |
| <1024 | 本阶段不支持移动端布局；显示“请使用 ≥1280 px 桌面浏览器”提示，页面仍可横向滚动只读 |

行高与字号在任何宽度下不缩小，避免可读性下降。

---

## 7. 可访问性

- 正文对比度 ≥ 4.5:1；状态徽标文字对比度 ≥ 4.5:1。
- 所有可交互元素有可见 focus ring（2 px `--accent` + 1 px 偏移）。
- 表格使用语义 `<table><thead><th scope>`；状态徽标附带文本，不只靠颜色。
- 导航使用 `aria-current="page"`；状态条更新使用 `aria-live="polite"`。
- 图标按钮必须有 `aria-label`。
- 支持键盘：Tab 顺序 = 导航 → 页面操作 → 表格；Enter/Space 激活。
- 遵循 `prefers-reduced-motion`，关闭旋转以外的所有过渡。

## 9. 明确禁止的视觉做法

1. 大面积渐变、玻璃拟态、发光边框、背景粒子。
2. 卡片内嵌套卡片超过一层。
3. 为“好看”增加无数据来源的图表。
4. 用状态色作为普通装饰色。
5. 把未实现数据画成 0 或空图表却不标注。
6. 在平台页内嵌 Console、缩放 Console 画布。
7. 自动播放动画/轮播/数字增长动画。
8. 全屏 loading 遮罩阻断导航。
9. 用图标替代必要文字（状态必须文字 + 颜色）。
10. 修改 Console 既有样式变量去“统一”视觉。
